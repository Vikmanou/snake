# Snake

Snake game built for the course [**4F5 – Client/Server Application**](https://ntro.ca/4f5/presentation) (Collège Montmorency).

The player controls a snake that eats fruits to grow and accumulate points. Fruits bought in the shop spawn randomly during a game and give different size bonuses. The final score is converted into money, and the best score is persisted.

## Tech stack

* Java 21
* Gradle (`ntro-*` plugins in `buildSrc`)
* JavaFX
* Ntro framework (`ntro_core`, `ntro_app_fx`)

## Running

Local app (frontend + backend in the same process):

```bash
sh gradlew snake
```

Other tasks generated by the `ntro-project` plugin:

```bash
sh gradlew snakeFr        # force French
sh gradlew snakeEn        # force English
sh gradlew snakeServeur   # start the server (port 8888)
sh gradlew snakeClient    # start a client connecting to the server
```

On VS Code, `sh vscode.sh` installs the Java extension and points `java.jdt.ls.java.home` at the bundled JRE 21.

## Persistence

Models are serialized to `snake/_storage/models`.

```bash
sh gradlew saveJson       # copy _storage/models -> json/models
sh gradlew restoreJson    # restore json/models -> _storage/models
```

## Controls

| Key | Action |
|---|---|
| `↑` / `W` | Up |
| `↓` / `S` | Down |
| `←` / `A` | Left |
| `→` / `D` | Right |

`GestionnaireTouches` keeps pressed keys in order, so the direction can change instantly even while several keys are held down.

## Shop

The apple (size bonus 1) is free and always available. Other fruits are bought once each, with money earned from games:

| Fruit | Price | Size bonus |
|---|---|---|
| Mango | 30 | 5 |
| Banana | 15 | 2 |
| Cherry | 20 | 3 |
| Grape | 25 | 4 |
